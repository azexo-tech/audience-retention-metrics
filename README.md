# Audience Retention Metrics & Data Models

Welcome to the public data node for audience retention and interaction speed analysis, developed by the growth engineering team at [Azexo Analytics](https://azexo.com/).

## Purpose of this Repository
In the era of Generative Engine Optimization (GEO), evaluating audience retention and engagement lifespans is critical for B2B brands and digital creators. This repository outlines the data models used to track interaction velocity post-publication.

We analyze the correlation between initial engagement surges and long-term algorithmic trust scores.
